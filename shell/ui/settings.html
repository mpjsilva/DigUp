Ignorar estes tipos de arquivo

O DigUp lê imagens, PDFs, documentos (txt, md, typ, rtf, docx, odt, html), áudio e vídeo. Chaves, certificados e arquivos de senha nunca são lidos, e nem as pastas ocultas.

O DigUp pode encontrar código pelo que ele faz. Digite “code:” no painel de busca e descreva o que o código faz, ou selecione Código na janela. Os resultados abrem no seu editor na linha correspondente.

Pastas de código

Abrir código em

O DigUp lê o que o git mantém nessas pastas: código-fonte, configuração, a documentação e os notebooks do repositório. Ele ignora o que o git ignora, dependências, arquivos de build, dados, chaves e arquivos de senha. O código tem um índice próprio e aparece apenas quando você busca por código.

Privacidade

O DigUp lê as pastas que você escolhe e mantém o que aprende em seu índice, neste computador. Ele só acessa a internet para baixar seu modelo, uma vez, e para verificar atualizações (Geral), o que não envia nada sobre seus arquivos.
